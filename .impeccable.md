# Impeccable

## Design Context

### Users

Developers and technical professionals capturing/annotating screenshots daily —
quick bursts of use (capture → annotate → share) in the middle of other work,
often at night, IDE and terminal open. Keyboard-first mentality.

### Brand Personality

Preciso, silenzioso, affilato — a precision instrument, not a toy.
The app should feel like a well-machined tool: quiet until needed, exact when used.
Privacy is the core promise ("your screenshots never leave this device") — the
visual language must feel trustworthy and local, never cloud-flashy.

### Aesthetic Direction

Precision-tool dark UI (dark default, honest light theme available):

- Warm graphite neutrals (OKLCH, hue ~70, chroma ≈0.006) — never pure black.
- One accent: signal amber (instrument lamp / viewfinder indicator), used at ~10%
  visual weight: active tool, focus, primary action, selection.
- Type: Hanken Grotesk (UI) + Fragment Mono (data: dimensions, shortcuts,
  timers, version, license keys). Self-hosted — the app is offline-first.
- 1px borders, small radii (6-8px), no glow, no glassmorphism, no gradients in
  chrome (gradients live only in the styled-copy export backdrops).
- Anti-references: AI-slop purple/cyan dashboards; CleanShot's soft consumer look.

### Design Principles

1. The screenshot is the hero — chrome recedes, content pops.
2. One accent, spent sparingly; hierarchy by weight and space, not color spam.
3. Numbers are data: always mono, always tabular.
4. Every interactive element has a visible keyboard path (focus ring, shortcut hint).
5. Quiet by default, exact on interaction — motion only as state feedback.
